# Modem Satellite C3 v1.2.0

После включения полётника и нового heartbeat ESP проверяет разрешение ARM в AUTO для ArduCopter:

- Читает AUTO_OPTIONS. Если бит 0 уже включён, ничего не записывает.
- Иначе записывает `старое значение | 1`, сохраняя остальные биты.
- После ответа на запись отдельно перечитывает параметр и сверяет полное значение.
- Затем загружает миссию, ждёт MISSION_ACK ACCEPTED, включает AUTO и ARM с подтверждением ACK и heartbeat.

В браузере показаны чтение/запись/проверка и значения AUTO_OPTIONS. На этап параметра — 10 секунд; чтение до 3 попыток, запись однократная. При ошибке, несовпадении или потере heartbeat последовательность останавливается. ARMING_CHECK, failsafe и опция взлёта без поднятия газа не изменяются. Для Plane/VTOL/Rover настройка Copter не применяется.

## ESP Flasher

Скачать **modem-c3-v1.2.0-full.bin**, выбрать **ESP32-C3**, **4 MB**, адрес **0x0**. Это полный образ, отдельная файловая система не нужна. Запись полного образа заменяет сохранённую миссию и настройки ESP.

ZIP-комплект содержит исходники и запускатели Windows/Mac. Wi-Fi **modem_bridge / 00000000**, страница **http://192.168.0.4**, первые 5 минут.

Сборка C3 и программные тесты проходят, включая обмен MAVLink на подставном UART, сохранение битов, подтверждение чтением, отказы, таймауты и отмену. На физическую ESP эта версия не записывалась. Первую проверку автоматического ARM проводить со снятыми пропеллерами.
