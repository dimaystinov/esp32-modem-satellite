# Modem Satellite C3 v1.1.0

После нового задания: GPIO4 HIGH → heartbeat → загрузка всех точек → MISSION_ACK ACCEPTED → AUTO → ARM.

**Изменилось поведение: успешная загрузка миссии теперь автоматически запускает AUTO и ARM.** ARM отправляется после подтверждения AUTO через ACK и свежий heartbeat. Применяются обычные проверки ArduPilot, force-arm не используется. Для Copter арming в AUTO должен быть разрешён настройками AUTO_OPTIONS.

В браузере добавлены этап AUTO/ARM, фактический режим/ARM, COMMAND_ACK и STATUSTEXT. Отказ, таймаут или потеря heartbeat останавливают последовательность. Stop sequence не делает DISARM и не отзывает отправленные команды. Автоматического повторного ARM после разоружения нет.

ESP32-C3 4 MB. Полный образ `modem-c3-v1.1.0-full.bin` записывать по адресу **0x0**. Комплект ZIP содержит исходники и запускатели Windows/Mac. Wi-Fi **modem_bridge / 00000000**, **http://192.168.0.4**, первые 5 минут.

Пройдены программные тесты настоящего MAVLink UART-кода с подставным портом, проверки приёма миссии, GPIO4 и UI, сборка C3. Аппаратная проверка и запись на ESP не выполнялись. Первую проверку автоматического ARM проводить со снятыми пропеллерами.
