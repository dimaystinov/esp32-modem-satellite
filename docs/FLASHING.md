# Прошивка ESP32-C3-MINI-V1

Репозиторий: https://github.com/dimaystinov/esp32-modem-satellite
Релизы: https://github.com/dimaystinov/esp32-modem-satellite/releases/latest

## Подключения

Полная таблица в README. Модем TX → GPIO6, RX → GPIO7. Полётник TX → GPIO3, RX → GPIO10. Оба UART 115200 8N1, 3,3 В, общий GND. GPIO4 управляет активным высоким уровнем входом силового ключа; ESP и модем питаются независимо от него. OLED опционален.

## Windows: сборка и запись

1. Скачать `modem-c3-v1.2.0-kit.zip` из релиза, распаковать целиком.
2. Подключить C3 кабелем USB с передачей данных; закрыть Serial Monitor.
3. Открыть `FLASH_WINDOWS.bat`. PowerShell скачает Arduino CLI и зависимости, затем соберёт и запишет прошивку. При нескольких портах выбрать COM порт ESP.
4. Дождаться SUCCESS. При ошибке сборки запись не начинается.

Нужны Windows 10/11 x64, PowerShell 5.1+ и интернет при первой установке. Windows ARM не проверен.

## macOS: сборка и запись

1. Распаковать комплект, подключить C3 и открыть `FLASH_MAC.command`.
2. При запрете запуска открыть Terminal в папке комплекта и выполнить `chmod +x FLASH_MAC.command`, затем `./FLASH_MAC.command`.
3. При нескольких последовательных устройствах выбрать порт ESP. Дождаться SUCCESS.

Поддерживаются Apple Silicon и Intel. Зависимости скачиваются автоматически, Python и Git этим запускателям не нужны.

## Готовый образ через ESP Flasher

Использовать флешер с поддержкой **ESP32-C3**, например Espressif Flash Download Tool (Windows) или esptool (Windows/macOS). Старые приложения только для ESP32 могут не поддерживать C3.

- Файл: `modem-c3-v1.2.0-full.bin`.
- Адрес записи: **0x0**, flash 4 MB, DIO, UART 460800 (при сбоях 115200).
- Это единый образ bootloader + partitions + application + пустая файловая система. Не записывать его по 0x10000. Он заменяет всю flash, включая сохранённую миссию.
- Для выборочной записи имеются отдельные app/bootloader/partitions в релизе, но предпочтителен полный образ. Файлы относятся только к ESP32-C3, не S3/C6.

Через Python esptool 4.11.0:

```sh
python3 -m pip install esptool==4.11.0
python3 -m esptool --chip esp32c3 --port /dev/cu.usbmodem101 --baud 460800 write_flash 0x0 modem-c3-v1.2.0-full.bin
```

На Windows заменить `python3` на `py -3`, порт на свой `COM5`. Проверить SHA256 по `SHA256SUMS.txt`: Mac `shasum -a 256 файл.bin`, Windows PowerShell `Get-FileHash файл.bin -Algorithm SHA256`.

## После записи

Подключиться к **modem_bridge**, пароль **00000000**; открыть **http://192.168.0.4**. При необходимости переподключиться к Wi-Fi, чтобы обновился DHCP. Сеть работает 5 минут от запуска, счётчик есть в интерфейсе. Затем UART и управление питанием продолжают работу.

GPIO4 при запуске LOW. Только новое принятое и сохранённое задание включает HIGH. После нового heartbeat для Copter проверяется AUTO_OPTIONS и при необходимости включается бит 0 с перечитыванием; затем начинается передача миссии; успешное подтверждение запускает AUTO, затем ARM с проверками ACK и heartbeat. Перезапуск ESP выключит GPIO4. Для загрузки прошивки питание подключённого полётника должно быть допустимо выключить.

Нет порта/связи: проверить USB-кабель; удерживать BOOT, нажать и отпустить RESET, затем отпустить BOOT. Повторно выбрать появившийся порт. Если плата осталась в загрузчике после записи, нажать RESET без BOOT.

Прошивка собирается и проверяется программными тестами. Работа с вашим модемом, полётником и ключом требует стендовой проверки; этот релиз не означает аппаратную проверку.
